# Metodologia

Os dados utilizados neste projeto foram obtidos no Sistema de
Informações Hospitalares do SUS (SIH/SUS), disponibilizado pelo DATASUS.

## Período analisado

Janeiro a abril de 2025.

## Processo

DATASUS → Tabwin → Google Planilhas → Tratamento → Análise

Os dados foram tabulados utilizando o Tabwin e posteriormente
organizados no Google Planilhas.

Foram realizados cálculos de:

- totais de internações;
- participação percentual por grupo de causas;
- variação entre os meses;
- perfil demográfico;
- valores totais e médios das internações;
- distribuição das internações e custos entre macrorregiões.

## Observação sobre a base

Os dados do DATASUS estão sujeitos a atualizações posteriores.
Por esse motivo, os resultados apresentados correspondem à versão
da base utilizada durante o desenvolvimento da análise.
