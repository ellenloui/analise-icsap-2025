# Análise das Internações por Condições Sensíveis à Atenção Primária

Projeto de análise de dados desenvolvido a partir de atividades
realizadas durante uma Iniciação Científica.

A análise utiliza dados públicos do Sistema de Informações
Hospitalares do SUS (SIH/SUS), disponibilizados pelo DATASUS,
referentes ao período de janeiro a abril de 2025.

## Objetivo

Analisar as Internações por Condições Sensíveis à Atenção Primária
(ICSAP) em Minas Gerais, considerando frequência de internações,
principais grupos de causas, perfil demográfico, custos hospitalares
e distribuição entre macrorregiões de saúde.

## Fonte dos dados

- DATASUS
- Sistema de Informações Hospitalares do SUS (SIH/SUS)

## Processo de análise

DATASUS → Tabwin → Google Planilhas → Tratamento → Indicadores → Visualizações

## Análises realizadas

- Quantidade de ICSAP por mês
- Distribuição por grupo de causas
- Variação mensal das internações
- Perfil demográfico
- Custos hospitalares
- Valor médio das internações
- Distribuição das internações por macrorregião
- Distribuição dos custos por macrorregião

## Ferramentas utilizadas

- DATASUS
- Tabwin
- Google Planilhas
- GitHub

## Estrutura do projeto

`dados/` - tabelas utilizadas na análise em formato CSV

`planilha/` - planilha utilizada para tratamento e análise

`metodologia/` - descrição do processo de obtenção e tratamento dos dados

## Observação sobre os dados

As bases do DATASUS podem sofrer atualizações posteriores.
Os resultados apresentados neste projeto correspondem à versão
utilizada no período de realização da análise.
